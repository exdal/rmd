# Compiler prelude

This crate owns the DM definitions compiled ahead of every project and the intrinsic ABI attached
to those definitions.

- `BYOND_VERSION` is the newest supported BYOND release. `build.rs` turns it into the `DM_VERSION`
  and `DM_BUILD` defines, which load ahead of `core.dm`. The stddef update workflow rewrites it
  together with `stddef.dm`.
- `core.dm` defines the root `/datum`, `/list`, and `/alist` types. It is mandatory and remains
  enabled when the optional prelude is disabled.
- `stddef.dm` contains generated BYOND standard definitions. **Do not edit it by hand.**
- `demir.dm` contains the remaining compatibility definitions, including `/world`, atoms, images,
  and compiler-supported global procedures.

`build.rs` reads intrinsic markers from `core.dm` and `demir.dm`, validates their numeric IDs, and
generates the Rust `Intrinsic` enum used by semantic analysis, IR, code generation, and the VM.
